# Pitch Trampu · até três minutos

Grave a navegação real no protótipo, o terminal Java e o banco. As falas deixam espaço para cliques e pausas. Ensaie com cronômetro e corte a espera entre telas para terminar até 3:00.

## Preparação

Use uma janela de demonstração com os dados iniciais. Separe duas abas na mesma origem. Na primeira, escolha **Joana Lima**. Na segunda, escolha **Flora Jardins**. O perfil ativo pertence à aba e as candidaturas são compartilhadas. Deixe o Java no menu inicial e o SQLite com a consulta do painel já aberta. Reserve uma terceira aba com o DER em tamanho legível.
